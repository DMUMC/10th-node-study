# 3주차 미션 발표 대본

---

## 오프닝 (약 30초)

안녕하세요, 저는 ○○○입니다.
이번 3주차 미션은 1주차 ERD를 기반으로 API 명세서를 설계하는 것이었습니다.
총 7개 API를 설계했고, 설계 의도 위주로 발표하겠습니다.

---

## 1번 - 회원 가입 (약 1분)

POST /api/v1/members 로 설계했습니다.

회원 가입은 새로운 리소스 생성이므로 POST,
자원은 복수형 members를 사용했습니다.

Request Body에 이름, 닉네임, 전화번호 같은 기본 정보와 함께
선호 음식 카테고리 ID 배열, 약관 동의 ID 배열도 포함했습니다.
ERD에 member_prefer, member_agree 테이블이 있기 때문에
가입 시점에 한번에 처리하는 것이 UX상 자연스럽다고 판단했습니다.

회원 가입은 로그인 전이므로 Authorization 헤더는 필요 없습니다.

---

## 2번 - 홈 화면 미션 목록 (약 1분 30초)

GET /api/v1/regions/{regionId}/missions 로 설계했습니다.

지역과 미션이 store를 통해 연관 관계가 있으므로
URI에 regions/{regionId}/missions 형태로 계층 관계를 표현했습니다.

페이징은 Query String으로 page, size를 받도록 했고,
Path Variable로 regionId를 받아 해당 지역 미션만 필터링합니다.

로그인한 사용자의 도전 여부를 확인해야 하므로
Authorization 헤더가 필요합니다.

---

## 3번 - 마이 페이지 (약 1분)

GET /api/v1/members/me 로 설계했습니다.

여기서 포인트는 /members/{memberId}가 아니라 /members/me를 쓴 것입니다.
Authorization 토큰으로 본인 식별이 가능하기 때문에
별도로 memberId를 Path Variable로 받을 필요가 없고,
다른 사용자의 정보에 접근하는 것도 방지할 수 있습니다.

---

## 4번 - 리뷰 작성 (약 1분)

POST /api/v1/stores/{storeId}/reviews 로 설계했습니다.

리뷰는 가게에 종속된 리소스이므로
stores/{storeId}/reviews 로 계층 관계를 표현했습니다.

Request Body에는 content와 score만 포함했습니다.
memberId는 토큰에서, storeId는 Path Variable에서 가져오므로
Body에 중복으로 넣지 않았습니다.

---

## 5번 - 내 미션 목록 조회 (약 1분)

GET /api/v1/members/me/missions 로 설계했습니다.

진행중과 완료를 구분하기 위해
Query String으로 status 파라미터를 받도록 했습니다.
CHALLENGING 또는 COMPLETE 값을 전달하면 해당 상태의 미션만 조회됩니다.

페이징도 Query String으로 처리합니다.

---

## 6번 - 미션 성공 처리 (약 1분)

PATCH /api/v1/members/me/missions/{missionId} 로 설계했습니다.

미션 전체를 수정하는 것이 아니라 status 필드만 COMPLETE로 변경하는 것이므로
PUT이 아닌 PATCH를 사용했습니다.

Request Body에 status: "COMPLETE"를 담아 보냅니다.

---

## 7번 - 미션 도전 신청 (약 1분)

POST /api/v1/missions/{missionId}/challenges 로 설계했습니다.

미션에 도전한다는 것은 member_mission 테이블에 새로운 행을 생성하는 것이므로
POST를 사용했고,
challenges라는 자원명으로 도전 행위를 표현했습니다.

Authorization 토큰으로 본인 확인이 되므로
Request Body는 필요 없습니다.

---

## 마무리 (약 30초)

이상으로 7개 API 설계 발표를 마치겠습니다.

설계하면서 가장 신경 쓴 부분은
첫째, URI에 리소스 간 계층 관계를 반영하는 것,
둘째, 토큰으로 식별 가능한 정보는 Body에 중복으로 넣지 않는 것,
셋째, 용도에 맞는 HTTP 메소드를 선택하는 것이었습니다.
감사합니다.
